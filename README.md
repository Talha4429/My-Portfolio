# Muhammad Talha - Portfolio

Personal developer portfolio website showcasing full-stack Ruby on Rails, Next.js, and software engineering projects.

## Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite 8
- **Styling:** Bootstrap 5.3 & Custom CSS
- **Fonts:** Syne & DM Sans (Google Fonts)

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Development
1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build locally:
   ```bash
   npm run preview
   ```
